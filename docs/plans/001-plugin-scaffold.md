## 次の修正：強調記号の非表示とカーソル移動

### 目的

`**strong**` の前後の `**` を非表示にし、Vim プラグインの有無にかかわらず、カーソルが記号の存在を意識せず移動できるようにする。保存する Markdown 本文は維持する。

### 修正案

- `link-compact` のエディタ拡張の登録方法を参考に、有効化時に拡張を登録し、無効化時に解除する。
- CodeMirror の Markdown 構文情報を利用し、強調記号を検出する。コード内の `**` や未成立の強調は非表示にしない。
- 置換装飾で開始・終了の `**` を非表示にする。本文にカーソルが入っても記号は非表示のままにする。
- `atomicRanges` で通常のカーソル移動が非表示の記号を飛び越えるようにする。
- 選択位置を補正する処理を追加し、Vim が直接設定する選択位置も非表示の記号に止まらないようにする。
- Vim の通常モードのブロックカーソルと挿入モードのカーソル位置の違いを考慮する。
- 範囲選択では方向と選択の起点を維持し、複数カーソルにも対応する。
- 必要な依存関係を `package.json` に追加し、`README.md` を実装内容に合わせて更新する。

### 検証

- 強調、隣接する強調、行頭・行末、入れ子、コード内、未成立の記号を確認する。
- 左右移動、行頭・行末への移動、上下移動、範囲選択、複数カーソルについて位置補正を検証する。
- Vim の通常モードと挿入モードの違いを想定した検証を行う。
- 編集後の装飾の更新と無効化時の解除を確認する。
- 実機の Inkdrop および Vim プラグインで未確認の項目は、完了時に明記する。

## Enter による強調記号の一時表示

- 修正案：非表示の強調本文内で最初の `Enter` を押すと、改行せず対象の開始・終了記号を表示する。
- 表示中の範囲では記号スキップと左端の `i` の特例を停止し、記号を含めて通常どおり編集できるようにする。
- 表示中の範囲で次に `Enter` を押した場合は、通常の改行処理へ渡す。
- カーソルが強調の全範囲（開始・終了記号を含む）の外へ移動した場合、記号を再び非表示にする。本文から記号へ移動しただけでは表示を維持する。
- 編集に伴う範囲の位置変更を追跡し、他の強調箇所は非表示のままにする。入れ子ではカーソルに最も近い強調範囲を対象にする。
- 通常エディタと Vim、範囲外への移動、再進入、表示中の編集を検証する。

### 実施結果

- 強調範囲の位置を構文解析で取得し、一時表示の状態と編集による位置変更を追跡する処理を追加した。
- 非表示箇所の Enter で表示し、範囲外への移動で非表示に戻す。
- 表示中の記号は移動時にスキップせず、Vim の `i` も通常の本文位置で動作する。
- 通常エディタ・Vim、他の強調箇所の非表示維持、再進入、表示中の改行・編集、入れ子を含む自動テスト 17 件が成功した。
